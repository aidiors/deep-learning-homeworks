Выполненный вариант CV

В hw2_cv.ipynb сохранены код, ответы и результаты всех заданий, включая бонусы 6.1, 6.2, 6.3, 6.4, 6.5.
FAST_MODE=False. Основной датасет BCCD, 364 изображения. Дополнительно размечены 50 изображений PBC.
Исходный запуск: RTX 5070, Windows, Python 3.14.7, torch 2.11.0+cu130.
Зависимости перечислены в requirements_cv.txt. Для GPU нужна подходящая CUDA-сборка PyTorch.
Для повторения положите extra/ рядом с ноутбуком и выполните Restart & Run All.
BCCD и исходные веса моделей скачиваются без ключей. Дополнительные изображения и новая разметка уже включены в extra/.
При наличии завершенных опытов с той же подписью данных и настроек используются их сохраненные результаты.
Для повторного обучения установите REUSE_COMPLETED_RUNS=False.
В artifacts/ сохранены основные веса best.pt, экспорт best.onnx, метрики, графики и CSV всех обучений.
extra50.json, rtdetr.json и export.json содержат результаты новых бонусов, analysis.json содержит все сравнения.
Источники и условия использования новых изображений указаны в extra/README.txt.
В репозиторий нужно положить ноутбук, artifacts/ и extra/. Папки data/ и runs_hw2/ добавлять не нужно.
